# 💜 Purple Snake - Xiaomi Watch 5 Active Edition

![Version](https://img.shields.io/badge/Version-5.5--Stable-purple)
![Device](https://img.shields.io/badge/Device-Watch_5_Active-black)

**Purple Snake**, Xiaomi/Redmi Watch 5 Active için özel olarak geliştirilmiş, yüksek akıcılığa sahip bir PWA (Progressive Web App) oyunudur.

## ⚡ Özellikler
- **Watch-Native:** 320x385 çözünürlük desteği.
- **PWA Support:** Çevrimdışı oynanabilir, ana ekrana eklenebilir.
- **Cyber-Aesthetic:** Purpleguy imzalı neon mor tasarım.
- **Hassas Swipe:** Küçük ekranlar için optimize edilmiş kaydırma kontrolleri.

## 🛠️ Dosyalar
- `index.html`: Ana yapı.
- `style.css`: Purple-Neon görseller.
- `script.js`: Oyun mantığı ve 120 FPS render.
- `sw.js`: Offline çalışma desteği.
